# Alla Litvinenko — Portfolio

Готовий статичний сайт для GitHub Pages.

## Що вже є
- `index.html` — головна сторінка
- `cases/` — 8 окремих кейсів
- `assets/style.css` — стилі
- `assets/script.js` — фільтри каталогу
- `assets/alla-litvinenko.jpg` — фото
- 2 PDF-версії CV
- Telegram, телефон, email і LinkedIn у контактах
- `.nojekyll`, `404.html`, `robots.txt`

## GitHub Pages
1. Створити GitHub-акаунт.
2. Створити public repository, наприклад `portfolio`.
3. Завантажити в корінь усі файли з цього ZIP.
4. Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: `main`, folder: `/ (root)`.
7. Save.
